# NOIRARA 헌정곡 시네마틱 뮤직비디오 제작 지시문 (수정본)

현재 프로젝트 폴더에 제공된 파일들을 사용해서 **완성된 64.824초 분량의 뮤직비디오를 제작해 줘.**

기획안만 작성하는 것이 아니라 Remotion을 활용해 실제 영상으로 구현하고 MP4 파일까지 렌더링해 줘.

기존에 설치된 모션그래픽·Remotion 관련 스킬이 있다면 먼저 확인하고 활용해 줘.

---

## 1. 프로젝트 정보

- 제목: NOIRARA — BEHIND THE LIGHT
- 목적: 사진작가님의 열정과 작품 세계에 감사하는 헌정 뮤직비디오
- 음악: `assets/audio/noirara_original.mp3`
- 음악 길이: **64.824초**
- 화면 비율: **9:16**

- 프레임: **30fps**
- 출력: **MP4(H.264)**

**음원은 절대 변경하지 마.** 가사, 보컬, 곡의 순서, 속도를 그대로 유지해.

## 2. 비주얼 콘셉트

**Cinematic Fashion Film + Korean Semi-Realistic Webtoon + Behind the Scenes**

연예인 화보 촬영 현장을 따라가는 뮤직비디오처럼 제작해.

초반에는 고급스러운 반실사 웹툰으로 짧은 이야기를 보여주고, 중반부터 실제 사진작가님의 현장 모습과 완성된 작품으로 자연스럽게 전환해.

### 전체 분위기
- 밝고 세련된 시티팝 분위기
- 영화 같은 카메라 연출
- 고급 패션 매거진 스타일
- 자연스러운 줌과 화면 이동
- 은은한 렌즈 플레어와 셔터 플래시
- 음악 박자와 맞는 컷 전환

### 피해야 할 것
- 슬프거나 지나치게 애잔한 분위기
- 과도한 특수효과
- 촌스러운 사진 슬라이드쇼 느낌
- 불필요하게 느린 인트로

## 5. 후렴 — 작품이 되는 순간

가사:

찰칵! 셔터 소리 한 번에  
가장 나다운 나를 만났죠  
두 번 세 번, 열 번이라도  
노이라라, 다시 찾아갈게요

여기서는 실제 노이라라 작품 사진들과 사용자의 사진을 활용해.

### 연출 지시
- **“찰칵!”** 에서는 셔터 플래시 시각 효과
- 실제 사진이 잡지 화보처럼 등장
- 여러 작품의 빠르고 세련된 컷 전환
- 인물 얼굴이 잘리지 않도록 이미지 배치
- 음악 비트에 맞춘 영상 리듬

사진이 평면적으로만 보이지 않도록 자연스러운 카메라 이동과 세련된 그래픽 레이아웃을 사용해.

**원본 작품은 웹툰으로 변환하지 마.**

## 7. 엔딩에 반드시 들어가야 하는 감사 문구

다음 3문장을 마지막 구간에서 순차적으로 보여줘.

### 순차 문구
1. **누군가의 가장 아름다운 순간을 발견하기 위해**
2. **늘 카메라 뒤에서 최선을 다하는 사람.**
3. **그 열정과 진심에 감사드립니다.**

### 연출 방식
- 첫 번째, 두 번째 문장은 실제 현장 사진 또는 완성 작품 위에 짧고 세련된 타이포그래피로 순차 노출
- 너무 길게 정지하지 말고, 읽을 수 있을 정도로만 노출
- 마지막 문장 **“그 열정과 진심에 감사드립니다.”** 는 최종 엔딩 메시지로 사용

또한, 아래 보조 문구는 필요 시 한 번만 보조적으로 활용 가능해:

> 나를 예쁘게 찍어준 사람이 아니라,  
> 나도 몰랐던 나의 빛을 꺼내준 사람.

이 보조 문구는 꼭 필수는 아니지만, 영상 흐름이 자연스러우면 짧게 활용해도 좋다.

## 8. 최종 로고/타이포 애니메이션 규칙 (매우 중요)

엔딩 최종 화면에서 **노이라라 영문 표기 애니메이션**을 넣어줘.

### 표기 규칙
- 표기는 반드시 **`Noirara`** 로 쓸 것
- 즉, **첫 글자만 대문자 N**, 나머지는 **소문자 oirara**
- 모두 대문자 `NOIRARA`로 쓰지 마
- 모두 소문자 `noirara`로 쓰지 마

### 애니메이션 규칙
- `N` → `o` → `i` → `r` → `a` → `r` → `a` 순서로
- **한 글자씩 순차적으로 등장하거나 움직이는 애니메이션**을 적용
- 너무 화려하지 않게, 고급스럽고 절제된 방식으로 표현
- 예: 페이드업 + 살짝 위로 떠오름, 또는 부드러운 트래킹 등장
- 전체가 한 번에 튀어나오는 방식보다 **한 글자씩 리듬감 있게 완성되는 방식** 선호

### 엔딩 최종 구성
최종 프레임에서는 아래 요소가 정리되어 보여야 해:

1. **실제 로고 또는 `Noirara` 타이포 애니메이션**
2. **그 열정과 진심에 감사드립니다.**

타이포는 고급스럽고 세련되게, 화면을 과하게 가득 채우지 않도록 해.

## 9. 제작 필수 조건

1. 전체 영상은 원본 음악의 **64.824초**에 맞춰 완성할 것.
2. 실제 음원을 분석하여 가사와 장면의 정확한 타이밍을 맞출 것.
3. 웹툰 이미지는 도입부에 집중하고, 실제 작품이 영상의 주인공이 되도록 할 것.
4. 사진 속 인물의 얼굴, 체형, 의상, 작품 구도를 변형하지 말 것.
5. 실제 사진 속 사람을 억지로 움직이게 만들지 말 것.
6. 웹툰 이미지의 인물에 부자연스러운 입 모양 애니메이션을 넣지 말 것.
7. 노이라라의 **원본 로고**를 사용할 것.
8. 모든 이미지의 원본 비율을 최대한 보존하고, 필요한 경우 배경을 확장해 세로 화면에 맞출 것.
9. 영상 하단에는 릴스 인터페이스와 겹치지 않도록 안전 여백을 확보할 것.
10. 불필요한 긴 인트로나 별도의 엔딩 음악은 만들지 말 것.
11. 마지막 타이포 애니메이션은 **`Noirara` 표기 규칙**을 반드시 지킬 것.

## 11. 최종 목표

최종 목표는 **연예인 화보 촬영 현장의 비하인드 영상처럼 세련되면서도, 작가님의 열정과 진심이 전해지는 헌정 뮤직비디오**야.

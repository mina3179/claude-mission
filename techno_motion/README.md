# 테크노자동차정비 원스톱 사고수리 — 30초 세로형 모션그래픽

**결과물:** `out/techno_onestop_30s.mp4` — 1080×1920 (9:16), 30fps, 30초, H.264 + AAC 스테레오

자막과 애니메이션만으로 내용이 전달되도록 만들었고, 내레이션은 넣지 않았습니다. 캐릭터, 자동차, 스마트폰, 지도, 정비소, 아이콘은 모두 Canvas 2D 코드로 직접 그린 2D 플랫 일러스트입니다.
스타일은 레퍼런스처럼 짙은 청록 라인, 하프톤 도트 유리창, 단순한 정비사 캐릭터를 쓰고, 색은 크림·옐로·민트·코랄 파스텔로 맞췄습니다.
배경음악과 효과음도 코드로 합성했기 때문에 외부 음원 라이선스 문제가 없습니다.

## 장면 구성

| 시간 | 장면 | 주요 연출 | 전환 |
|---|---|---|---|
| 0–4s | 사고는 났는데… | 시무룩한 자동차가 뿅 등장하고 눈을 깜빡임. 직장인이 시계를 보고 당황함. 시계가 빠르게 돌고 일정 카드가 쌓임 | — |
| 4–8s | 바쁘다 바빠! | 제자리 달리기와 함께 출근·일·집안일 아이콘이 지나감. 7.15초에 화면이 멈추고 음악도 멈추며 **?** 가 팡! 등장 | 물결 와이프 |
| 8–12s | 걱정 마세요! | 폰이 통통 튀며 등장. 손상 부위를 촬영(찰칵)하고 사진을 전송하면 상담 채팅에 답장이 옴. 예상 견적 고지 문구 포함 | 물음표 위치에서 원형 아이리스 |
| 12–15.4s | 무료 픽업 | 지도 위에 핀이 생기고, 픽업 차량이 도착하면 내 차가 점선 경로를 따라 정비소로 이동 | 폰 화면으로 줌인 |
| 15.4–20s | 무상대차 | 키를 건네받고 노란 대차 차량이 뿅 등장. 고객이 운전하며 일상을 이어가는 모습(커피·가방·하트). 이용 조건 고지 문구 포함 | 자동차가 가로지르며 와이프(슝) |
| 20–24s | 수리 과정 안내 | 정비소에서 점검하고 판금·도장(스프레이)을 하면 긁힘이 사라짐. 푸시 알림과 단계 표시(상태 확인 → 수리 진행 → 완료 알림) | 사선 스트라이프 |
| 24–27s | 딜리버리 | 반짝이는 차를 정비사가 운전해 집 앞에 도착. 고객은 놀랐다가 기뻐하고, "어? 정비소에 안 갔는데 벌써 끝났네?!" 말풍선이 뜸 | 별 모양 아이리스(반짝) |
| 27–30s | 브랜드 엔딩 | 자동차 캐릭터가 웃으며 바운스. 별·하트·반짝이와 함께 메인 카피, 김해 테크노자동차정비, CTA 표시 | 원형 아이리스 |

**안전 영역:** 중요한 자막과 요소는 y 260–1500px 사이에 있습니다. 상단 프로필 영역과 하단 캡션·버튼 영역은 비워 두었습니다.

## 폴더 구조

```
techno_motion/
├─ index.html            # 브라우저 미리보기 플레이어 (재생/스크럽, Space=재생)
├─ src/
│  ├─ core.js            # 팔레트, 이징, 도형, 키네틱 타이포(kText)
│  ├─ characters.js      # 직장인·정비사·자동차(정면/측면)·폰·지도핀·아이콘·로고 마크
│  ├─ scenes.js          # 8개 장면 (scene1 ~ scene8)
│  └─ main.js            # 타임라인, 장면 전환 마스크, 효과음 큐(SFX)
├─ audio/make_audio.py   # BGM(우쿨렐레 KS 합성 등) + 효과음 합성 → out/audio.wav
├─ render/render.js      # Playwright로 프레임 렌더 → ffmpeg 인코딩
├─ fonts/                # Jua(OFL), 나눔스퀘어라운드 Bold(OFL)
├─ build.sh              # 전체 빌드
└─ out/                  # techno_onestop_30s.mp4, audio.wav, sfx_cues.json
```

## 다시 빌드하기

필요한 것: Node 18+, Playwright(Chromium), Python 3, numpy, scipy, ffmpeg

```bash
pip install numpy scipy
```

```bash
./build.sh
```

4코어 기준 약 40초 걸립니다. 결과는 `out/techno_onestop_30s.mp4` 입니다.

특정 시점만 PNG로 뽑아서 확인하려면 다음 명령을 씁니다.

```bash
node render/render.js --stills 1.5,9.6,25.5
```

`index.html`을 브라우저로 열면 소리와 함께 실시간으로 미리 볼 수 있습니다. `?t=12` 처럼 시작 시간을 지정할 수도 있습니다.

## 자주 하는 수정

- **자막 문구:** `src/scenes.js`에서 `kText(...)` 호출을 고칩니다. `{ t: '문구', c: C.coral, hl: 1 }` 형식이고, `hl`은 강조 바운스입니다.
- **색상:** `src/core.js`의 `C` 팔레트를 바꿉니다.
- **장면 타이밍과 전환:** `src/main.js`의 `TIMELINE`을 수정합니다.
- **효과음 위치:** `src/main.js`의 `SFX` 목록을 고친 뒤 `./build.sh`를 다시 실행하면 오디오도 다시 합성됩니다.
- **실제 로고 적용:** `src/characters.js`의 `drawLogoMark`를 이미지 그리기(`ctx.drawImage`)로 바꾸면 됩니다. 로고 파일을 받지 못해서 지금은 심볼 + 텍스트로 표현했습니다.
- **조건부 서비스 고지:** 사진 견적과 무상대차 고지 문구는 `note(...)` 호출에 있습니다.
